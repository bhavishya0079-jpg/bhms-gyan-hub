# Medical Study AI with BR

Mobile-friendly educational website for BHMS study organization and an Allopathy medicine reference starter library.

## Upload
Upload the contents of this folder to the root of your GitHub repository (not the containing folder itself). Keep paths and filenames unchanged.

## GitHub Pages
1. Open repository **Settings → Pages**.
2. Set **Build and deployment → Source** to **GitHub Actions**.
3. Commit/push the files to the `main` branch.
4. Open **Actions** and wait for the Pages workflow to finish successfully.
5. Open the published URL shown by the deployment.

## Important project status
This repository is a starter implementation. The four-year subject catalogue is an initial list and must be checked against the current NCH and HNGU curriculum. The question-paper entries are source leads, not a verified complete HNGU archive. The medicine JSON contains only sample reference records. Medicine image upload currently previews the selected image only; it does not identify the medicine. There is no AI backend or database in this static GitHub Pages version.

Do not add unverified medical claims, doses, paper labels or copyrighted PDFs. Record sources and verification status for every item.
